# Conversor de Medidas

## Objetivo
Aplicação web interativa para conversão de valores entre diferentes unidades de medida (Comprimento, Peso e Temperatura), facilitando cálculos rápidos do dia a dia.

## Tecnologias
HTML, CSS e JavaScript.

## Funcionalidades
O conversor permite selecionar categorias de medidas, inserir um valor numérico e escolher as unidades de origem e destino. Ao clicar no botão, a interface exibe o resultado do cálculo na mesma página. As conversões de comprimento (metros, km, cm), peso (kg, g, libras) e temperatura (Celsius, Fahrenheit, Kelvin) já estão implementadas e funcionando.

## Como executar
Abra o arquivo index.html no navegador.
